# Бот-сервер для оплаты доступа (Telegram Stars)

Что это: маленький сервер, который умеет продавать «Полный доступ» за Telegram Stars и
запоминает, кто уже заплатил — прямо в твоей существующей Firebase Realtime Database
(проект `memes-millennials`, та же база, что уже используется для мультиплеера). Игра
(index.html) спрашивает у сервера «этот юзер платил?» и открывает/закрывает рубрику
«Кино и сериалы» в зависимости от ответа.

Список оплативших хранится по отдельному пути `paidUsers/<telegram_id>` — с игровыми
данными мультиплеера никак не пересекается.

## Шаг 1. Ключ доступа к Firebase (service account)

1. Открой [Firebase Console](https://console.firebase.google.com/) → выбери проект
   `memes-millennials`.
2. Перейди в **Project Settings** (шестерёнка сверху слева) → вкладка **Service accounts**.
3. Нажми **Generate new private key** → подтверди — скачается файл `.json`.
4. Открой этот файл любым текстовым редактором (блокнотом) — весь его текст целиком
   понадобится на шаге 3. Никому не показывай и никуда не выкладывай этот файл — он даёт
   полный доступ к твоей базе данных.

## Шаг 2. Render (хостинг для сервера)

1. Зайди на render.com, зарегистрируйся (можно через GitHub).
2. Нажми **New → Web Service**.
3. Подключи свой GitHub-репозиторий с игрой (тот же, куда заливаешь картинки).
4. В настройках сервиса укажи:
   - **Root Directory**: `bot-server` (важно — сервер лежит в подпапке, не в корне репо)
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: Free
5. Пока не нажимай Create — сначала заполни переменные окружения, см. шаг 3.

## Шаг 3. Переменные окружения в Render

В разделе Environment добавь:

| Ключ | Значение |
|---|---|
| `BOT_TOKEN` | токен твоего бота от @BotFather (команда `/mybots` → выбрать бота → API Token) |
| `WEBHOOK_SECRET` | любая длинная случайная строка (придумай сам, например `kg7f3n9x2mQpL8vR`) |
| `FIREBASE_SERVICE_ACCOUNT` | весь текст JSON-файла из шага 1, целиком, как есть |
| `FIREBASE_DATABASE_URL` | `https://memes-millennials-default-rtdb.europe-west1.firebasedatabase.app` |
| `STARS_PRICE` | `100` |
| `ALLOWED_ORIGIN` | `https://povidlo1212-wq.github.io` |

Теперь нажми **Create Web Service**. Дождись, пока сборка завершится (статус станет
«Live») — Render покажет адрес сервиса, что-то вроде `https://meme-game-bot.onrender.com`.
Сохрани этот адрес, он нужен дальше.

## Шаг 4. Подключить вебхук Telegram

Открой в браузере (просто вставь строку адреса, подставив свои значения):

```
https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=<RENDER_URL>/webhook/<WEBHOOK_SECRET>
```

где:
- `<BOT_TOKEN>` — тот же токен, что в переменных окружения
- `<RENDER_URL>` — адрес из шага 2 (без слэша на конце)
- `<WEBHOOK_SECRET>` — та же случайная строка, что в переменных окружения

Если всё правильно, в ответ увидишь `{"ok":true,"result":true,"description":"Webhook was set"}`.

## Шаг 5. Указать адрес сервера в игре

В файле `index.html` найди (например через Ctrl+F в блокноте/редакторе) строку:

```js
var KINO_BACKEND_URL='https://YOUR-BACKEND.onrender.com';
```

и замени `https://YOUR-BACKEND.onrender.com` на свой реальный адрес из шага 2 (без
слэша на конце). Залей обновлённый `index.html` на GitHub поверх старого, как обычно.

## Шаг 6. Проверка

1. Открой игру через Telegram-бота (не напрямую в браузере — Stars работают только внутри
   Telegram).
2. На карточке «Мемы из фильмов и сериалов» должна появиться кнопка «Купить доступ ⭐100»
   вместо «ИГРАТЬ».
3. Нажми — должно открыться нативное окно оплаты Telegram Stars.
4. После оплаты бот пришлёт сообщение «Спасибо за покупку!», а кнопка в игре (если
   вернуться на экран рубрик) должна снова стать «ИГРАТЬ».
5. Проверить руками: в Firebase Console → Realtime Database должен появиться узел
   `paidUsers` с твоим Telegram ID внутри.

## Важно понимать

- Render на бесплатном тарифе «засыпает» после ~15 минут без запросов и просыпается
  ~30–50 секунд при следующем обращении — первая проверка доступа после простоя может
  занять чуть дольше обычного. Для этой задачи это не критично.
- Доступ проверяется в момент, когда игрок сам нажимает «ИГРАТЬ» на карточке рубрики.
  Если один человек купил доступ и создал комнату с рубрикой «Кино и сериалы», друзья,
  которые присоединяются по коду комнаты, отдельно оплату не проходят — доступ фактически
  открывается на уровне того, кто начинает игру. Если нужно, чтобы каждый участник комнаты
  оплачивал доступ индивидуально — это отдельная доработка, скажи, сделаем.
- `FIREBASE_SERVICE_ACCOUNT` даёт серверу полный административный доступ к базе данных —
  храни его только в переменных окружения Render, никогда не вставляй в код игры
  (`index.html`) и не публикуй в открытом репозитории.
